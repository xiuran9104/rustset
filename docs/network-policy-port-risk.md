# 网络策略高风险端口预警

网络策略属于当前认证租户。动作是 `allow` 时，服务端解析 `service_port` 并与
`infra_high_risk_port_rule` 基线匹配；动作是 `deny` 时不产生预警。

支持以下端口写法：

- 单端口：`22`
- 多端口：`80,443`
- 范围：`8080-8090`
- 协议：`tcp/3389`、`udp:137-139`
- 全端口：`*`、`any`、`tcp/*`

创建、修改和 CSV 导入网络策略时，策略写入与风险同步在同一数据库事务内完成。
删除策略、改为拒绝或移除高风险端口会把对应风险标记为已解决。人工标记为“忽略”或
“误报”的结果不会被自动覆盖。历史策略可在网络策略页面执行“重新匹配风险”。

风险使用 `tenant_id + network_policy:{policy_id}:{rule_id}` 作为稳定键，同一策略和规则
不会重复创建记录。网络策略列表显示当前有效的高风险预警数量，风险管理页面显示来源。

租户、资产、网络策略和 CMDB 实例台账统一使用 UTF-8 CSV（含 BOM）导入导出。CSV
导入上限为 5 MiB、10000 行；公式样式的文本会转义，导入结果按行返回成功和失败明细。
